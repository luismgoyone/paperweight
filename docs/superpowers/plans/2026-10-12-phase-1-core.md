# Phase 1 (Core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static, browser-only PDF viewer with the engine, op-log/undo, download and privacy enforcement that every later phase builds on.

**Architecture:** MuPDF.js runs in a module Web Worker behind a Comlink `EngineApi`. The UI thread holds an op log (`editor/history.ts`) and asks the engine to converge the live document to "original bytes + ops[0..cursor]" using in-worker checkpoints. React renders virtualized page canvases from `ImageBitmap`s the worker produces. Privacy is enforced by CSP headers (single source in `vercel.json`, also applied to `vite preview`), an ESLint ban on storage/beacon/absolute-fetch APIs, and a Playwright test that watches every network request and storage API.

**Tech Stack:** Vite 8, React 18.3, TypeScript 6.0 (strict), MuPDF.js 1.28, Comlink 4, Zustand 5, Tailwind 4, Vitest 5, Playwright 1.64, ESLint 10 + Prettier 3.

**Spec:** `docs/superpowers/specs/2026-10-12-pdf-editor-design.md` (§3, §5, §6 Phase 1, §7, §8, §9, §10)

## Global Constraints

- No backend: static files only, no API routes.
- Nothing persisted: no cookies, `localStorage`, `sessionStorage`, IndexedDB, service worker or document caching.
- No third-party network calls; all assets (WASM, fonts) self-hosted, same origin. No CDNs, analytics, Google Fonts.
- CSP exactly: `default-src 'self'; connect-src 'self'; img-src 'self' blob: data:; worker-src 'self' blob:; script-src 'self' 'wasm-unsafe-eval'; style-src 'self' 'unsafe-inline'; font-src 'self'; frame-ancestors 'none'`, plus `Referrer-Policy: no-referrer` and a `Permissions-Policy` disabling unused features.
- `engine/` never imports from `ui/` or `editor/`; `ui/` never imports `mupdf`; everything that changes the document is an `Op`.
- License AGPL-3.0; app shows a "Source code" link.
- Download file name: original name with `.pdf` replaced by `-edited.pdf`.
- Zoom: fit width, fit page, 50–400%.
- Large files: warn above 200 MB.
- Tools not built yet are hidden, not disabled.
- Dependencies: only those named in the spec plus the tooling glue they require (`@vitejs/plugin-react`, `@tailwindcss/vite`, `typescript-eslint`, `@eslint/js`, `eslint-plugin-react-hooks`, `globals`, `@types/react`, `@types/react-dom`, `@types/node`). TypeScript pinned to 6.0.x because `typescript-eslint` requires `<6.1`. React pinned to 18.3.x per spec.

## Review Focus

1. **Corrupt / non-PDF file dropped** → clear inline error, app stays usable (test in Task 3 and Task 9).
2. **Wrong password, then right password** → inline "Wrong password" and retry works without reopening the picker (Task 3 engine test, Task 9 e2e).
3. **Undo after more than 20 ops, then a new op (branch)** → state equals replaying the surviving ops; stale checkpoints beyond the branch are discarded (Task 4).
4. **File without `.pdf` extension or uppercase `.PDF`** → download name still ends in `-edited.pdf` (Task 6).
5. **Search term with no hits / searching before a doc is open** → "No results", no crash; Enter cycles results and wraps (Task 8).

### Task 4: Op log — engine convergence + editor history

**Files:** Create `src/engine/ops/meta.ts`, `src/engine/ops/index.ts`, add `setOps()` to `src/engine/document.ts`, create `src/editor/history.ts`, tests `tests/unit/engine-ops.test.ts`, `tests/unit/history.test.ts`.

**Interfaces — Produces:**

```ts
// engine/ops/index.ts
export function applyOp(doc: mupdf.PDFDocument, op: Op): void; // throws OpError on failure
export class OpError extends Error {}
// EngineSession
setOps(ops: Op[]): { changedPages: number[] | 'all' }; // converge live doc to original + ops
readonly checkpointIndices: number[];                  // for tests
// editor/history.ts
export class History {
  readonly ops: readonly Op[]; readonly cursor: number;   // ops[0..cursor) are applied
  get active(): Op[]; canUndo: boolean; canRedo: boolean; dirty: boolean;
  push(op: Op): void;      // truncates redo tail
  undo(): void; redo(): void; reset(): void; markSaved(): void;
}
```

Convergence algorithm in `setOps(target)`: let `p` = length of common prefix of `applied` and `target` (deep-equal via `JSON.stringify`). Drop checkpoints with index > `p`. If `target` extends `applied` exactly (`p === applied.length`), apply the tail incrementally. Otherwise reopen from the largest checkpoint `k ≤ p` (`0` = original bytes) and apply `target.slice(k)`. While applying op number `i` (1-based count of ops applied), take a checkpoint (`doc.saveToBuffer('incremental')` bytes — fall back to full save) **before** any op whose kind is in `DESTRUCTIVE_KINDS` and **after** every 20th op. If an op throws, restore the previous state (re-converge to `applied`) and rethrow `OpError` so the UI can report it.

```ts
import { test, expect } from '@playwright/test';

test('no network after load, no third-party hosts, nothing stored', async ({ page, context, baseURL }) => {
  const origin = new URL(baseURL!).origin;
  const requests: { url: string; phase: 'load' | 'after' }[] = [];
  let phase: 'load' | 'after' = 'load';
  page.on('request', (r) => requests.push({ url: r.url(), phase }));

  await page.goto('/#e2e');
  await page.waitForLoadState('networkidle');
  await page.getByTestId('engine-ready').waitFor({ state: 'attached' }); // worker + wasm loaded
  phase = 'after';

  await page.getByTestId('file-input').setInputFiles('tests/fixtures/simple.pdf');
  await expect(page.getByTestId('page')).toHaveCount(3);
  await page.evaluate(() => (window as any).__editor.commit({ kind: 'meta.setTitle', title: 'x' }));
  await page.getByLabel('Search').fill('needle');
  await page.keyboard.press('Enter');
  const download = page.waitForEvent('download');
  await page.getByRole('button', { name: 'Download PDF' }).click();
  await download;

  const foreign = requests.filter((r) => !r.url.startsWith(origin) && !r.url.startsWith('blob:') && !r.url.startsWith('data:'));
  expect(foreign).toEqual([]);
  expect(requests.filter((r) => r.phase === 'after' && !r.url.startsWith('blob:') && !r.url.startsWith('data:'))).toEqual([]);

  const storage = await page.evaluate(async () => ({
    local: localStorage.length,
    session: sessionStorage.length,
    idb: (await indexedDB.databases()).length,
    cookie: document.cookie,
    sw: (await navigator.serviceWorker?.getRegistrations())?.length ?? 0,
    caches: 'caches' in self ? (await caches.keys()).length : 0,
  }));
  expect(storage).toEqual({ local: 0, session: 0, idb: 0, cookie: '', sw: 0, caches: 0 });
  expect(await context.cookies()).toEqual([]);

  const res = await page.request.get('/');
  expect(res.headers()['content-security-policy']).toContain("connect-src 'self'");
});
```

(The test file is in `tests/`, outside the lint ban on storage APIs, which applies to `src/` only.) The app must render a hidden `<span data-testid="engine-ready">` once the worker has finished loading WASM, and Task 7's engine client must start the worker eagerly at app load so WASM is fetched during the load phase, not after the user picks a file.
